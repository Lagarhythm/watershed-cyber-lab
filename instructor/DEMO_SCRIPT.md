# Faculty demonstration script — 20 minutes

> This guide covers the optional code-oriented companion. For the current visual student app, use [SIMULATION_GUIDE.md](SIMULATION_GUIDE.md).

Before presenting, use a fresh package copy, select its installed kernel, run all cells and confirm widgets render. Secure-code failures are intentional. Keep the facilitation guide privately available and reset old progress.

| Time | Show and execute | Notice / why it matters | Suggested talking point |
|---|---|---|---|
| 0–2 | Title, navigation, inventory, progress, rationale disclosure | One environment carries the learning route | “We explain, manipulate, and assess the same evidence.” |
| 2–4 | Change one hash input character, then equalize both; check prediction | Learner action tests a property immediately | “This interaction also works for scientific variables and model parameters.” |
| 4–6 | Integrity comparison; select collector_config.txt and decode | One method yields the next evidence lead | “Decoding produces clues to verify, not a conclusion to trust.” |
| 6–8 | Filter logs to research-07/riley, search sync_agent; show pandas example | Scaffold analysis before requiring code | “Students can first reason with controls, then learn the underlying query.” |
| 8–10 | Filter network by research-07/sync_agent; compare routine backup traffic | Chart and table support hypothesis testing | “Regularity alone is ambiguous. Correlation strengthens the finding.” |
| 10–13 | Run failed checks; repair lookup_user with `?` and `(username,)`; rerun | Security and ordinary functionality are assessed together | “A check should test useful behavior, not a screenshot.” |
| 13–17 | Submit one wrong stage-1 answer, request hints, complete six stages using private guide | Stages unlock and progress updates; token appears on completion | “Feedback supports recovery without removing reasoning.” |
| 17–19 | Enable instructor view; inspect local record and separate simulated cohort | Attempts and hints suggest where to reteach | “The local record is real; the cohort is simulated. Hub aggregation is a future integration.” |
| 19–20 | Show customization guide; invite a dataset/question from each discipline | Reusable teaching patterns | “What could your students investigate here that a static handout cannot let them test?” |

If time is short, show the first stage and discuss the later evidence using the guide. Do not imply a precompleted session represents the audience's learning. Full completion requires the secure-query repair.

Troubleshooting: plain-text widgets indicate an installation/kernel issue. Empty tables call for clearing filters. After editing the query, rerun its definition before checks. Reset clears progress but does not overwrite saved code or notes.
