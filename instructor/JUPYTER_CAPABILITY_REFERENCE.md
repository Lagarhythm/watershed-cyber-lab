# Capability and activity reference

> This guide covers the optional code-oriented companion. For the current visual student app, use [SIMULATION_GUIDE.md](SIMULATION_GUIDE.md).

This matrix records the PRD's eight activity fields: objective, capability, instructor value, interaction, assessment, CTF link, data, and expected result.

| Activity / objective | Capability and interaction | Instructor value | Assessment / expected result | Data / CTF connection |
|---|---|---|---|---|
| Briefing: separate observations from conclusions | Markdown navigation, collapsible rationale, progress, executable inventory | Keep the route and evidence together | Case-note discussion; identify task and sources | Manifest and telemetry; establishes the case |
| Integrity: verify bytes | Live text widgets and changed-bit count; pandas comparison | Make an abstract property testable | Prediction check; exactly one mismatch | Manifest and files; stage 1 filename |
| Artifacts: distinguish representation from secrecy | File selector, decoding checkbox, format feedback | Explore file operations without separate tools | Base64 classification and decoded leads | Collected files; stage 2 account |
| Logs: correlate observations | pandas, dropdowns, literal search, sort controls, dynamic chart | Scaffold reasoning before query code | Routine-host check; correct process event | Authentication/system CSVs; stage 3 and access context |
| Network: test a traffic hypothesis | Protocol/host/process filters, address search, count chart | Compare benign and suspicious patterns | Protocol check; correlated destination | Network CSV; stage 4 |
| Secure coding: separate code and data | Editable Python and SQLite checks | Repair security while retaining functionality | Five checks pass, including apostrophes and injection | Portal source and AUTH-041; stage 5 |
| Investigation: explain the incident | Sequential validation, three-level hints, progress, generated token | Combine skills into a continuous recoverable lab | Six findings/order plus manually reviewed note | All evidence; final reconstruction |
| Instructor view: identify difficulty | Optional panel, local stage table, simulated cohort chart | Make reteaching opportunities visible | Interpret attempt/hint patterns | Local JSON and clearly simulated cohort |

Persistent state supports multi-session work. Validation outside visible cells reduces clutter but is inspectable. Reset supports repeated demonstrations. Every chart includes exact table values and a text summary; success and failure use words, not color alone. Sort tables through the Sort by and Descending controls.
